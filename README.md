# 警然企业微信 SCRM 原型

按本期合同表达客户、业务记录和发送任务管理。员工继续在企业微信聊天，网页不提供代聊。

## 本地运行

在源码目录启动静态服务器后访问本机地址。页面使用浏览器原生模块，无需安装依赖。

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:4173/#/customers 。工作台页面及概括卡片已删除，旧工作台地址进入现有客户管理页。默认销售视角，载入5个演示客户、3条成交、4条咨询／回访、2个客户群、2条个人话术及一段欢迎语示例。所有数据均为专门制作的假数据，页面统一标明。管理员具体权限及主管团队范围尚待确认，切换角色仍按现有规则控制数据范围，不默认授予全员权限。

## 本期页面

- 客户资料、归属、标签、批次、群分类；同步和异常补查结果；跨活码回最早员工的核对边界。
- 发送任务：单客、批量客户或群选择，跨标签全选；文本、图片、文件和公众号普通链接；员工确认、结果和停止待发的流程边界。
- 按年级批量改群名；隔日、7天、14天筛选未打标签新客的回访任务；带昵称的新客欢迎语。
- 咨询、回访、下次回访时间及时间筛选。
- 成交登记、退费关联原订单；四类主管查询、客户四维统计、业绩报表。
- 系统内公共文件与图片素材；个人话术；本人一类成交明细导出。
- 管理员、主管、销售的范围说明及待确认权限。

## 可核对的本地操作

1. 浏览合同功能页面及三种角色视角；初始假数据仅用于演示，不代表实际企微同步或授权结果。
2. 查看演示客户、关联成交、咨询／回访、下次回访日期、客户群和个人话术；只填已有字段，不增加页面、字段或流程。
3. 发送对象选择及内容准备保留；删除自行补出的步骤条、保存草稿及草稿状态。不模拟企微执行、送达或停止成功。
4. 保留个人话术创建、管理；正式使用入口待确认，不假定复制就是使用入口。
5. 新客欢迎语保留合同要求；不规定昵称占位语法，不模拟事件或发送成功。
6. 选择本地文件或图片仅预览；离开页面会释放预览链接，不上传文件。

演示数据由预览入口传入，状态模块自身默认仍为空。所有页面录入仅在当前页面内存中，刷新后恢复初始演示数据，不写数据库或企微。不制作发送成功、群改名成功或同步成功记录，不补统计及退费口径。

## 待确认与接入限制

未确认的角色权限、团队范围、归属调整、标签写回、退费规则、金额统计、去重与占比分母、回访起算点和退出规则、群命名规则、平台额度及素材规格保留待确认。相关真实操作被禁用，不伪造同步、发送、群改名或审批成功。

未确认的标签写回和欢迎语操作不会保存成模拟成功。批量修改已有群名、重复客户跨不同活码仍指向最早添加员工均保留为合同要求，尚无官方接口及实际授权验证结果，不标记为已支持，也不以普通群查询、活码配置或手工交接替代。

素材选择仅用于原型预览，不代表正式管理权限已经取得。没有工作台、网页聊天、财务到账审批、作废和交接审批、分期提醒、目标管理、多班连报及合同签署管理。

## 验证

使用 Docker Node 24，无需安装宿主机 Node 或额外依赖：

```bash
docker run --rm --network none -v "$PWD:/workspace:ro" -w /workspace node:24-bookworm node --test tests/prototype.test.mjs
```

浏览器核对客户管理假数据及标识、成交和记录关联、群列表、欢迎语示例、角色范围及刷新恢复；工作台等合同外页面不出现，发送无自编步骤和草稿，欢迎语无占位语法。真实企微、生产授权和后端安全验收不由静态原型代替。
