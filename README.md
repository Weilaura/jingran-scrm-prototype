# 企业微信 SCRM 高保真原型

这是一个无需安装依赖的本地静态原型，使用原生 HTML、CSS 和 JavaScript 构建。

## 本地运行

在当前目录执行：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问：

```text
http://127.0.0.1:4173
```

## Vercel 部署

项目已通过 `vercel.json` 将 `dist` 配置为静态发布目录。将本目录导入 Vercel 后，无需填写构建命令即可部署。

## 已覆盖页面

- 管理员与销售双角色工作台
- 三栏会话工作台与账号筛选
- 客户模糊搜索、添加记录和后台交接
- 成交列表与成交录入
- 财务确认、退费、作废和客户交接审批
- 业绩与客户数据导出
- 企微账号绑定与角色权限矩阵

## 可演示流程

1. 在右上角切换管理员或销售视角。
2. 在会话页查看客户的重复添加提示和添加记录。
3. 发起后台交接，确认客户侧无感知。
4. 录入成交并提交财务确认。
5. 在审批中心确认到账，订单状态变为已处理。
6. 在客户页输入昵称的一部分，体验模糊搜索。
