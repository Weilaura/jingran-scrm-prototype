# 警然企业微信 SCRM 高保真原型

这是一个可直接在浏览器打开的静态交互原型，用于演示企业微信多账号客户运营、会话协同、成交与回访流程。所有人物、账号和业务记录均为虚构演示数据；页面操作仅保存在浏览器内存中，刷新后恢复初始状态。

## 在线地址

- GitHub Pages：<https://weilaura.github.io/jingran-scrm-prototype/dist/#/dashboard>
- 源码仓库：<https://github.com/Weilaura/jingran-scrm-prototype>

## 本地运行

项目不需要安装依赖，进入源码目录后运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后访问 <http://127.0.0.1:4173/#/dashboard>。

## 原型范围

- 销售看板：项目成交总数、成交金额、待回访、待补合同与退费待办。
- 会话工作台：会话容量说明、重要会话置顶、快捷回复、工作账号切换、管理员 `@所有人`、所在群聊和右侧业务入口。
- 客户管理：搜索全部授权账号联系人，按添加时间、企微账号、标签筛选，查看标签人数和客户明细。
- 回访与咨询：左侧独立回访、咨询子菜单；会话右侧可设置回访；咨询记录包含咨询项目和内容。
- 成交与退费：会话直接录入成交、上传成交截图、提交退费申请、成交后补录合同。
- 群发与群聊：群发任务、发送对象和账号选择；群聊切换工作账号或管理员账号。
- 交接流程：原销售接收通知、新销售接受、历史记录保留和管理员追溯。
- 标签同步：明确展示首次同步保留已有企业微信标签，同名标签去重并每日增量同步。

所有关键入口均已配置页面跳转、弹框、选中态或操作提示，适合用于产品评审和需求确认。真实会话容量、企业微信接口额度、消息发送和审批结果仍以正式接入配置为准。

## 验证

使用 Node 24 或更高版本运行：

```bash
node --test tests/prototype.test.mjs
```

测试覆盖路由与角色、客户筛选、项目统计、成交截图、合同状态、咨询记录、退费申请、标签管理、会话交互入口和所有主要弹框。

## 协作

仓库使用 `main` 分支。其他同事可以运行：

```bash
git clone https://github.com/Weilaura/jingran-scrm-prototype.git
```

修改前先拉取最新代码，提交前运行测试并检查差异。静态原型不连接真实企业微信、数据库或支付系统。
